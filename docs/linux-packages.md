# Linux x86_64 distribution

Build with `npm ci`, `npm run build`, then `PMM_RELEASE_REPOSITORY=OWNER/REPO npx electron-builder --config electron-builder.config.cjs --linux AppImage deb rpm --x64 --publish=never`. Set `PMM_PACKAGE_MAINTAINER` to the distributor's name and email; the default attributes the workflow repository owner. Install `rpm` before running `node scripts/package-artifacts.cjs` to inspect actual DEB/RPM metadata, require the artifact matrix and generate checksums/evidence and a pinned Arch PKGBUILD. The recipe's AppImage URL is for the exact version and selected release repository. Publish those exact assets together before using the recipe.

AppImage uses the app's updater only when build-selected authority exists. DEB/RPM use their package manager. The Arch wrapper sets `PMM_PACKAGE_MANAGED=1` and installs extracted resources under `/opt`; the app must not replace those resources. Native packages install a shared desktop/icon/executable identity. They do not intentionally select a new default URL handler or remove user mod/config directories. Separate application identities/coexistence remain installation work; this recipe uses the existing application identity.

Downloadable DEB/RPM are installers, not signed APT/DNF feeds. The PKGBUILD is not an AUR publication. No ARM/Flatpak support is added. Example lifecycle validation on disposable hosts: Debian `apt install ./PACKAGE.deb`, install the next version, `apt remove peakymodmanager-v3`; Fedora `dnf install ./PACKAGE.rpm`, upgrade, remove; Arch `makepkg -si`, build/install the next recipe, `pacman -R peakymodmanager-v3-bin`. Verify preserved user data and the chosen default handler at each step.

Artifact inspection and headless packaging do not prove interactive install/upgrade/uninstall, browser handling or games. Those checks and GNOME/KDE/X11/Wayland evidence remain required in application #13 before claiming support. Automated lifecycle containers and packaged smoke coverage are tracked by #8. The automatic release workflow is owned by #12.
